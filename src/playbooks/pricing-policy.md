# 가격 정책

> 전 제품 배송비 포함형(무료배송) 하나로 가격을 매긴다. 2026-11-26 사용자 지시로 별도형(마트형·낱개, 배송비 9,900원)과 300g 자동 분류는 기록·계산 방식째 삭제 — 가격 설정은 다시 정립한다.

## 1. 계산

- 판매가 = 상품가 + 집운 운임 + 수수료 + **차익 2,000원** (마진 5% 바닥, 자사몰 8%). 소비자 표시는 무료배송.
- 판매가는 100원 단위 올림. 수수료: 네이버 6.63%, 쿠팡 11.66%.
- 예전 별도형 상품(낱개, 쿠팡·네이버 판매중지)은 판매가가 별도형 기준이라 그대로 두고, 자사몰에서는 `product.shop_hidden` 으로 숨겨 둔다. 다시 팔려면 포함형으로 다시 계산한 뒤 연다.
## 매입가 기준 (2026-11-22 사용자: "지금 할인이면 할인가 기준으로 해")

- 가격 계산의 매입가(product_option.price_cny)는 **지금 1개 살 때 실제로 내는 값**(超级立减·限时补贴·百亿补贴 등 화면에 자동 적용된 할인 후 1개가)으로 적는다. 다건 조건(2件·3件)이나 따로 받아야 하는 쿠폰은 넣지 않는다.
- 1인 1개 한도(限购1件) 할인은 1개짜리 옵션에만 쓰고, 묶음(x2 이상) 옵션은 정가로 계산한다.
- 11-17 '원래 가격 기준'은 그날 등록분에만 쓴 결정 — 이 규칙으로 대체.
- **나중에 비싸지면 비싸진 값으로 다시 올린다** (2026-11-26 사용자: "추후에 비싸지면 비싸진거로 재업로드"). 할인이 끝나 실제 결제가(또는 다시 본 타오바오 1개가)가 매입가보다 비싸지면, 승인 질문 없이 price_cny 를 새 값으로 고치고 판매가를 같은 규칙(포함형 차익 2,000원 / 별도형 마진 20%)으로 다시 계산해 마켓(쿠팡·네이버·자사몰) 가격까지 바로 바꾼다. 바꾼 뒤 제품·옵션·이전→새 매입가·이전→새 판매가를 보고한다.
  - 감지: 04:30 점검(ops-check 10-2)의 `buy_dearer` (실제가 10%↑), 가격조사 재확인, 구매 때 결제가.
  - 반대로 더 싸진 경우(`buy_cheaper`)는 지금처럼 알리고 판단 후 내린다 (자동 인하 아님).
